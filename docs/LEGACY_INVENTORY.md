## Domain adapters to consider later

Convergent Superconductivity Engine, Phase-Comb Theorem, SpinoTensorVector, NGW, worldsheet soliton and related mathematical/physical modules may be registered as **domain workers**, not merged into the control plane as trusted axioms. The same applies to DriftCycle, SpiralBloomSignature, φ_Φ_Law, ErrorField, CacheBurn and Anti-Dilution, which need testable operational contracts before promotion. The exact current code, licenses and invariants of these modules were not recovered during this build.

## Exclusion

**InfiniteRoom and its family are intentionally out of scope**, per the project owner's request. No source, model, kernel, metric, or import from this family is included.

## Preservation rule

An unported name remains an inventory item. It becomes an executable plugin only after: input/output schema, semantics, ownership, failure contract, license audit, and runnable tests are all pinned. Cosmetic renaming alone does not count as integration.
