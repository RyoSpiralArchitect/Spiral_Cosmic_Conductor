# Original-module crosswalk / provenance of ideas

| Historical component | Current placement | Status |
|---|---|---|
| Cosmic Conductor, stage/mode harmonization | `conductor/runtime.py`, `control.py` | Concrete budgeted orchestration; tone control kept outside verification |
| Brotherhood, PRSN capability boundaries | `conductor/multipolar.py`, `ledger.py` | Scopes, distinct agents, refusal, one-use grants |
| Narrative Kernel | `conductor/narrative.py` | Hash-referenced chronological projection, not auto-generated narrative memory |
| ND-RAG / NarFS | `conductor/evidence.py`, SQLite event log | Scoped evidence identity only; full legacy format not ported |
| EBRT | `conductor/backtracking.py` | Structural rollback only; native EBRT gradient algorithm remains external |
| Tri-Phase | `conductor/control.py`, `runtime.py` | Cost/deadline routing only; original multidimensional optimizer not ported |
| A2E | `conductor/telemetry.py` | Measured bytes/tokens/latency and explicit nulls for unavailable metrics |
| SIG, ALR, ActionRegistry | `ledger.py`, `adapters.py`, `multipolar.py` | Scoped execution/verification boundaries; no comprehensive semantic-risk classifier |
| SpiralTorch | `conductor/spiraltorch_bridge.py` | Capability-check/proposal contract only; not executed |
| InfiniteRoom (all versions) | **excluded** | No import, no code |

This is an **integration nucleus**, not a claim that the complete historical implementations have been faithfully ported. The approach is contract-first to prevent undocumented, incompatible module semantics from silently changing the verifier or control plane.
