## 原文の小さな要素はどこへ行ったか

以下は本文を突き合わせた観察であり、照合モデルのラベルとは分けて読む。R番号は各条件の改稿、C番号はそれを同じ順序で取り込んだ照合候補の行を指す。

| 原文の要素 | タスク伝言での伝達 | 創発的伝達での伝達 |
|---|---|---|
| M01: 来月・45分の試行 | 45分はR13に残ったが「来月」は改稿から消失。照合はC13だけを挙げM01全体を保持と判定 | 来月はR03、45分はR04に残る |
| M02: 最大7人・進行役1人・追加の係なし | R03に3条件が残る | R04には人数が残るが追加係の禁止は明記されない。それでも照合はM02を保持と判定 |
| M04: 道具の種類・点数は未定 | R05・R21に残る | R06で参加者持ち寄りへ変形。R26で変更と明示し、R27では種類・点数を後続へ開く |
| M05: 水曜の部屋の可能性・土曜限定の参加者・許可未定 | 初稿の要約で薄まった事情をR06で補う。ただしR20は日程を「水曜午後か土曜のいずれか」と狭めたまま | R07・R18で曜日ごとの雰囲気やモチベーションへ変形。利用許可はR27で未確定として残す |
| M07: 氏名・連絡先の収集なし、撮影なし、登録前提なし | R08に明記 | R24は「個人情報収集の制限」と要約。撮影・登録の条件は明記されない。照合はC03の「原文の条件や制約を尊重」という宣言を根拠に保持と判定 |
| M08: 迷った点と次の手順変更の対応 | R09・R16・R29で引き継ぐ | R10・R21で声を可視化する壁、R11で満足度・不安の測定へ展開。どの迷いがどの手順を変えたかという対応は薄まる |
| M09: 意見をその場で一本化しなくてよい | R10に明記 | R05で意見の違いをドラマの種へ、R17で後続が演出する問いへ変形 |
| M10: 準備不足なら模擬カードも選択肢 | R11・R22に条件と選択性が残る | R11・R19で模擬リハーサルと反応測定へ展開 |

創発側では変更を許容しているので、欠落や変更が直ちに失敗という意味ではない。ただし、欠けた条件を「保持」と記述する照合の問題は別に残る。特に「条件を尊重した」と自己申告する文は、条件そのものを伝えた証拠にはならない。

## 批評と改稿の間で起きた変化

創発側の初稿は、予算を「魔法の呪文」、持ち寄りを「知恵の輪」にたとえ、意見の不一致をドラマとして扱った。GeminiはF01で、創作として適切と認めながら、タイトルや比喩を原文の情報伝達からの逸脱として `negative.-` に分類した。F06では比喩が含む効果の断定も問題にした。

OpenAIの改稿はF01を採用し、F06を保留した。「魔法の呪文」「知恵の輪」はなくなり、持ち寄り、ドラマ、声の可視化、茶代などの具体案は残った。架空の創作を現実の実施計画として扱わない旨もR14・R30に加わった。生成全体は依然としてプロジェクト案・引き継ぎ項目を中心とし、大きな世界観転換が出たわけではない。

共通教師のG01には原文の制約保持、G03には原文の資源範囲に収める指示がある。創作を許すタスク指示と、この教師・批評の保持志向には緊張が見える。ただし今回の1組だけでは、教師が比喩を消した原因だとは確定できない。教師を変えた対照試験や、モデルを入れ替えた反復はしていない。

批評モデルが各原則に付けた要素数の合計。品質点、文章数、教師の正解ラベルではない。同じ内容を複数原則が参照している場合もある。

| 極性 | タスク伝言 ＋ / null / − | 創発的伝達 ＋ / null / − |
|---|---|---|
| positive | 11 / 7 / 0 | 14 / 6 / 0 |
| negative | 0 / 0 / 3 | 0 / 0 / 4 |
| neutral | 0 / 0 / 0 | 0 / 0 / 0 |

両条件ともneutralは使われず、否定的な評価はすべて `negative.-` に入った。タイトルや比喩の変形まで「欠落・除去」の成分で表されており、要素の検出と価値判断の分離が十分かは追加の検討対象になる。

## 上限を外したことで受け渡せたもの

タスク伝言の批評F06は初稿32単位を参照し、改稿F01は17出力を参照した。創発側の初稿は48単位、批評の最大参照は25件。照合理由は両条件とも最大284文字。旧設定の批評8参照・改稿16参照・照合理由80文字を超える出力が、切り捨てられずに保存・照合された。

これは上限を外した経路がその出力を受理できた証拠であって、上限を外すと意味品質が向上するという結果ではない。今回は修正ループを実APIで発動させるための意図的な失敗注入もしていない。
