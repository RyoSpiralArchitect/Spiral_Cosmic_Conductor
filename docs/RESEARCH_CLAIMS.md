# Verified vs not assessed

## Directly exercised locally

- Fixed deterministic task; one deliberately wrong upstream fact, dependency invalidation and repair.
- Scope grants, stale-read rejection, replay/recovery and optional local HTTP protocol guards.
- Multipolar capsules, refusal, inaccessible per-agent private context via API, conflict records.
- Artifact integrity receipts, per-event chronology, bounded evidence lookup, route decisions.
- Test matrix: `python3 -m unittest discover -s tests -v`.

## Not assessed / not claimed

- Real-model generalization, accuracy, chain-of-thought quality, benchmark superiority.
- Robustness to malicious in-process workers, compromised local LLM server, or malicious source data.
- Independent third-party attestation, signatures, immutable secure time.
- Physical power consumption, calibrated meaning score, neural activation dynamics.
- Parallel multi-model throughput, learned adaptive routing, distributed consensus.
- Native EBRT reverse-mode gradients or actual SpiralTorch kernel execution.

The sample benchmark panel checks deterministic mechanics, not natural-language reasoning quality. Report negative, null and aborted results separately from passed contract tests.
