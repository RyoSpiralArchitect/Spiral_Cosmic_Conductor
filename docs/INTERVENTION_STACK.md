# Duet / Breath / Reflux / branching memory

An opt-in intervention library, developed in four dependent PRs. Existing
structured reasoning, transmission comparison and observation-only emergence
experiments remain unchanged. InfiniteRoom remains excluded. AGPL-3.0-only.

1. [Duet](DUET.md): four two-participant modes and durable scoped reservations.
2. [Breath](BREATH.md): explicit explore/compare/recompose/yield/hold phases.
3. [Reflux](REFLUX.md): target-owner routing and critic/annotation correction.
4. [Branching memory](BRANCH_MEMORY.md): retained decisions, fork/rewind/merge,
   condition-based reconsideration, and selected-context return to a duet.

```text
frozen source + host policy
  -> independent/leading/braided duet candidates
  -> explicit comparison phase
  -> declared finding + host-selected return plan
  -> targeted candidate or retained alternative branch
  -> selected public decision memory
  -> next explicit round or held/yielded-unassessed result
```

## What this does not claim

These APIs reserve and accept calls but do not dispatch providers. No live run,
model benchmark, quality improvement, calibrated meaning/attention measure,
actual EBRT gradient integration, or SpiralTorch device execution was performed.
Control events are host decisions, not automatic semantic detection. The code
cannot isolate hostile Python running in the same process. Hashes and replay
provide local integrity, not authenticated authorship or trusted timestamps.

No observer results are wired into generation. A separate future intervention
experiment must report its feedback and evaluation roles distinctly. New
`yield` results remain unassessed; source-fidelity tasks still require the existing
source-comparison gate. The old experiment configurations, artifacts and code
are not rewritten by this stack.

## Testing

Run the four targeted unittest modules (scripted fixtures only). GitHub's existing
Contract tests workflow also discovers them alongside the current full suite.
The implementation session made no live model/API request and accessed no model
credentials. No automatic loops, downloads or live CI commands were added.
